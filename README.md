# 💡 Portfólio Pessoal | Python & Streamlit

Bem-vindo ao repositório do meu portfólio web! Este espaço foi criado para reunir e demonstrar aplicações práticas desenvolvidas em Python, utilizando o Streamlit para interfaces web interativas e o Stlite (WebAssembly) para rodar tudo diretamente no navegador de forma totalmente estática.

O projeto está publicado em: **[codebybueno.com.br](https://codebybueno.com.br)**

---

**👋 Sobre Mim**

Formado em Análise e Desenvolvimento de Sistemas, atuo fora da equipe formal de TI em um ambiente hospitalar. Sempre movido pela curiosidade e pela busca de eficiência, desenvolvo pequenos sistemas e automações por conta própria para resolver gargalos reais, eliminar planilhas repetitivas e otimizar fluxos de trabalho no dia a dia.

---

**🚀 Aplicações em Produção**

As ferramentas a seguir rodam integradas ao ecossistema Streamlit Cloud:

* **GAPP CME:** Aplicação central para apoiar a organização, controle e os fluxos de trabalho dentro da Central de Material e Esterilização.
* **CME Pedidos:** Sistema focado em agilizar o controle e gerenciamento de pedidos de materiais e insumos.
* **Solicitação de Unidades:** Interface para facilitar os pedidos de materiais vindas dos diversos setores do hospital para a CME.
* **Gerador ZPL:** Ferramenta prática para geração e formatação de códigos ZPL para impressão de etiquetas de identificação.

---

**🚧 Em Desenvolvimento**

* **Track CME:** Sistema voltado ao rastreamento e acompanhamento detalhado de itens e processos na CME, visando maior rigor operacional.
* **DocFlow:** Ferramenta projetada para automatizar a geração, organização e o fluxo de documentos e relatórios institucionais.

---

**🛠️ Tecnologias Utilizadas**

* **Python:** Linguagem base para toda a lógica e manipulação de dados.
* **Streamlit:** Framework para criação rápida das interfaces web.
* **Stlite / Pyodide:** Execução de Python no navegador via WebAssembly para hospedagem estática.
* **HTML/CSS & Git:** Estruturação da página e controle de versão.
